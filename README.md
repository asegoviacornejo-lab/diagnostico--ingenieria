# Sistema inteligente de organización académica y personal

Primera versión funcional en Streamlit y SQLite.

## Ejecutar

```powershell
pip install -r requirements.txt
streamlit run app.py
```

La aplicación guarda los datos en `organizador.db`.

## Incluye

- Registro e inicio de sesión con correo.
- Configuración inicial con progreso.
- Perfil, energía diaria y valor SCT editable.
- Asignaturas, metas académicas y notas objetivo.
- Responsabilidades y metas personales.
- Horario semanal de lunes a domingo.
- Evaluaciones editables.
- Guías de ejercicios con avance por comprensión.
- Registro de estudio con reflexión.
- Dashboard con recomendación explicada.
- Revisión semanal y estadísticas de semestre.
- Historial de semestres sin borrar información anterior.
